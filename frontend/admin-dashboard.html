Workload Scoring Methodology Note

Workload Score = (Assigned Learners x 1.0) + (Class Cohorts x 3.0) + (Subject-Class Preparations x 2.0) + (Targeted Support Learners x 3.0) + (Monitoring Learners x 1.5). These classifications (HIGH, MODERATE, LOW, UNASSIGNED) are system-defined operational triage indicators established for administrative resource allocation. Unread notifications and operational alerts are displayed for administrative context only and do not factor into the score. This score is NOT a clinically or scientifically validated measure of teacher burnout or official Ministry of Education workload standard. This index is an administrative operational heuristic designed to highlight assignment disparities and intervention burdens.
